# 中国古代文学史（一）· 期末题库

按 2026 年期末考试题型做的网页题库：**模拟考 → 自动判分 → 对答案 → 记错题**。纯静态页面，不需要服务器，已经部署在 GitHub Pages 上，手机点开就能刷。

**在线版**：<https://yesnewbeebar.github.io/JNU-gudai-wenxue-questionbank/>

- 名词解释 5 题 × 3 分 = 15 分
- 填空题 30 空 × 0.5 分 = 15 分
- 默写题 3 选 1 = 10 分
- 简答题 2 题 × 10 分 = 20 分
- 分析论述题 2 题 × 20 分 = 40 分（标点 5 + 字词 5 + 论述 10）

## 功能

- **模拟考**：按上述结构随机组卷，150 分钟倒计时，到点自动交卷。
- **自动判分**：填空逐空比对（简繁、标点自动归一）；默写逐字对齐，标出错字、漏字、多字，按"每字扣 1 分、封顶 3 分"计分。
- **点选标点**：论述材料按句切成小段，点标点框再从符号面板里选，系统逐句比对。
- **主观题自评**：名词解释、简答、论述给出参考答案 + 得分点清单，勾选即算分，总分实时更新。
- **可选 AI 批改**：在设置里填自己的大模型 API（默认 DeepSeek），可按得分点给出分数与评语。Key 只存在浏览器本机。
- **错题本**：答错自动收录，可单题重做、标记已掌握；自评改对后会自动移出。
- **背诵篇目**：87 篇原文可检索，点开可"默写自测"。
- **成绩统计**：历次分数、分题型正确率。
- **离线可用**：完整版注册了 Service Worker，断网也能做题。
- **随处可退**：除首页外每页左上角都有「← 返回」，回到上一页；模拟考中途返回会先确认，答案保留、计时不停。

## 怎么打开

**方式一（最简单）**：把 `单文件版.html` 发到手机，用浏览器打开即可，全部功能都在一个文件里。

**方式二**：在项目目录起一个本地静态服务：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

直接双击 `index.html` 也能用，只是 Service Worker 离线缓存不会生效。

## 部署到 GitHub Pages

已部署：<https://yesnewbeebar.github.io/JNU-gudai-wenxue-questionbank/>，走 `main` 分支根目录，推到 `main` 就自动发布。

改完题库 `git push` 后等 1～2 分钟线上就更新。浏览器有 Service Worker 缓存，如果手机上还是旧题，把 `sw.js` 里的 `CACHE = "gdwx-v1"` 版本号加一。

从零建站的完整步骤见 [部署说明.md](部署说明.md)；每次 push 会跑一遍 `node tools/check.js` 做数据自检（`.github/workflows/check.yml`）。

## 判分规则

- **归一化**：去掉空白和标点，繁体转简体后再比较。所以写繁体、少写逗号都不扣分。
- **填空**：每空独立判分，0.5 分；全空即 0 分。
- **默写**：把答案与原文做最长公共子序列对齐，错、漏、多各算一处，扣分 `min(3, 错误数)`，最低 7 分。
- **论述标点**：按句比对，得分 = 正确句数 / 总句数 × 5。
- **字词**：答案支持 `/` 分隔多个可接受说法，含通假说明时按包含关系宽松匹配。
- **主观题**：默认需要自己勾选得分点；若配置了 API Key，可让模型按同一份得分点打分。

## 加题 / 扩展

所有题目都是普通 JS 数组，改 `data/` 下对应文件即可，改完跑一遍自检：

```bash
node tools/check.js
python3 tools/build_standalone.py   # 重新生成单文件版
```

一道名词解释的最小结构：

```js
{
  id: "t037", ch: "诗经", term: "笙诗",
  answer: "参考答案……",
  points: [{ t: "得分点一", w: 1 }, { t: "得分点二", w: 1 }, { t: "得分点三", w: 1 }],
  note: "出处"
}
```

`points` 的 `w` 之和：名词解释为 3，简答为 10，论述的"论述"部分为 10。

填空题的 `stem` 用连续全角下划线 `＿＿＿` 表示空位，`blanks` 按顺序给答案；填空题和默写题也可以用 `tools/build_fills.py`、`tools/build_recites.py` 从 `materials/背诵文本.md` 重新生成。

## 说明

- 题库依据课堂笔记与背诵文本整理；笔记只到《尚书》《左传》，诸子以下的答案以背诵文本和通行文学史教材为据，供复习参考，不保证与老师讲稿完全一致。
- A 卷为繁体卷面，本网站统一用简体显示，判分时简繁等价。
- AI 批改是浏览器直连模型接口，若遇到跨域限制会失败，此时用自评即可。
